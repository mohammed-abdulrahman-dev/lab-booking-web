# Lab Reservation System - UI

A web interface for booking lab facilities.

> **Status:** Early Development. Currently building the structural HTML interface. CSS styling and full backend integration will be added in upcoming updates.

## Current Features
- HTML form structure for reserving lab resources
- Form input validation (required fields and selection dropdowns)

## Tech Stack
- **HTML5** (Structure)
- *(Planned)* CSS3 & JavaScript
- *(Planned)* FastAPI backend integration

## How to View
Open `lab.html` directly in any standard modern web browser.
